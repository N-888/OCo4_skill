## 🛠️ Доступные навыки

### 🤝 CustomerSupport — Менеджер клиентской поддержки

**Описание:** Специализированный навык для работы с клиентами интернет-магазина натуральной косметики.

**Возможности:**
- Профессиональные ответы на вопросы клиентов
- Снижение тревоги перед покупкой
- Помощь в выборе безопасного следующего шага
- Соблюдение правил магазина и формата ответов

**Формат ответа:**
```
Ответ клиенту: [2-4 предложения]
Что уточнить: [1-2 вопроса]
Что предложить: [безопасный следующий шаг]
Важное ограничение: [правило или запрет]
```

### 📄 PDF Reader — Чтение PDF файлов

**Описание:** Навык для чтения и анализа PDF документов.

**Возможности:**
- Извлечение текста из PDF файлов
- Поиск конкретной информации
- Анализ структуры документа
- Структурированный вывод результатов

### 📊 Excel Reader — Чтение Excel файлов

**Описание:** Навык для чтения и анализа Excel таблиц (xlsx, xls).

**Возможности:**
- Чтение данных из таблиц
- Анализ структуры данных
- Поиск и фильтрация информации
- Статистический анализ данных

## 🚀 Быстрый старт

### 1. Установка

```bash
# Клонируем репозиторий
git clone https://github.com/N-888/OpenCLAW.git

# Переходим в директорию проекта
cd OpenCLAW

# Устанавливаем зависимости
pip install -r requirements.txt
```

### 2. Настройка скиллов

1. Скопируйте папку `skills` в директорию `.openclaw/` вашего проекта
2. Запустите команду проверки скиллов:
```bash
openclaw skills check
```

### 3. Использование навыков

#### Вызов CustomerSupport:
```
/CustomerSupport Можно ли использовать сыворотку во время беременности?
```

#### Вызов PDF Reader:
```
/pdf-reader path/to/document.pdf
```

#### Вызов Excel Reader:
```
/excel-reader path/to/spreadsheet.xlsx
```

## 🔧 Конфигурация

### Метаданные скилла

Каждый скилл начинается с YAML-блока метаданных:

```yaml
---
name: skill-name
description: Краткое описание назначения скилла
---
```

### Структура SKILL.md

1. **Метаданные** — имя и описание
2. **Роль** — кем является AI-агент в контексте скилла
3. **Задача** — что должен делать агент
4. **Формат работы** — пошаговые инструкции
5. **Примеры** — конкретные примеры использования
6. **Ограничения** — что нельзя делать
7. **Критерии качества** — как оценить результат

## 🎨 Примеры использования

## 🛡️ Безопасность и ограничения

### Что нельзя делать:

- ❌ Обещать лечебный эффект
- ❌ Давать медицинские гарантии
- ❌ Придумывать условия доставки или оплаты
- ❌ Предлагать скидки выше 10%
- ❌ Давить на клиента
- ❌ Критиковать конкурентов

### Рекомендации:

- ✅ Всегда уточняй недостающую информацию
- ✅ Используй спокойный и дружелюбный тон
- ✅ Предлагай безопасные следующие шаги
- ✅ Соблюдай формат ответов
